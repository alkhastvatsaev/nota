# Plan embauche dev — 7 jours (80/20)

Objectif : **être employé comme développeur**.  
Pas de SEO, pas de portfolio parfait, pas d’articles.  
Cette semaine = conversations → essai → CDI.

---

## Principe

Les boîtes embauchent surtout via :

1. quelqu’un qui te recommande
2. un fondateur / CTO qui te voit builder
3. un essai court qui réduit leur risque

Ton levier = **NOTA** (produit réel, pas un tuto).

---

## Message type (copier-coller)

> Salut [Prénom], j’ai construit un CRM terrain full-stack (Next.js/TS/Firebase) : interventions, carte, facturation, PWA.  
> Voici 90s de démo : [Loom]  
> Vous cherchez un dev qui livre ? Je peux démarrer cette semaine, même en essai court.

Propose explicitement : **1–2 semaines d’essai payé, puis CDI si ça matche**.

---

## Positionnement (1 phrase)

> Alkhast Vatsaev — développeur full-stack. Je construis des apps métier (CRM terrain) avec Next.js, TypeScript et Firebase : carte, interventions, facturation, mobile PWA.

---

## Jour 1 — Arme de guerre (2–3h)

- [ ] Enregistrer un **Loom 90 secondes** de NOTA  
      Ordre : carte → intervention → facture → mobile
- [ ] Finaliser le **message type** ci-dessus avec le lien Loom
- [ ] Lister **30 cibles** (pas 300) :
  - SaaS FR < 50 personnes
  - Agences product / ESN qui recrutent **maintenant**
  - Strasbourg / remote FR
  - Stack proche : Next.js, TypeScript, Firebase

Outils pour trouver des cibles : Welcome to the Jungle, LinkedIn (“Next.js”, “TypeScript”), sites “équipe”.

---

## Jours 2–5 — Volume (seul vrai KPI)

Chaque jour :

- [ ] **10 messages LinkedIn** au **fondateur / CTO / lead tech** (pas RH)
- [ ] **5 mails** directs (`prenom@boite.com` / Hunter / page équipe)
- [ ] **2 appels** si tu as un contact / numéro

Total cible ≈ **50–70 contacts** en 4 jours.

### Relances

- [ ] Relancer ceux qui ont vu / ouvert / liké sans répondre (J+2 / J+4)

---

## Jour 6 — Canal rapide

- [ ] Profil **Malt** up + 10 candidatures missions Next.js / React
- [ ] Profil **Comet** up + candidatures
- Objectif : mission courte → prolongation / CDI

---

## Jour 7 — Conversion

- [ ] Relancer toute la liste chaude
- [ ] Proposer l’essai payé 1–2 semaines
- [ ] Objectif semaine : **3 conversations techniques** minimum

---

## Chemins non standards (en parallèle)

| Action                                                                      | Pourquoi                          |
| --------------------------------------------------------------------------- | --------------------------------- |
| Demander à **10 personnes** : « Tu connais une boîte qui recrute un dev ? » | 1 reco > 100 candidatures         |
| Cibler les boîtes **même stack** que NOTA                                   | Crédibilité immédiate             |
| PR / bugfix sur le repo d’une boîte cible, puis message                     | « J’ai déjà touché votre code »   |
| Meetup / Discord Next.js / Strasbourg tech **cette semaine**                | Embauche = conversation           |
| Agences apps métier                                                         | Jugent au shipping, pas à l’école |
| Pitch « je livre X en 5 jours » (feature précise)                           | Tu vends un résultat, pas un CV   |

Pour chaque cible :

Tu ne cherches pas la notoriété.  
Tu cherches **3 conversations techniques cette semaine**.  
Ensuite 1 essai. Ensuite le CDI.
